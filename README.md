# Chalksmith

Chalksmith is an original offline-first whiteboard project for sketching, thinking, and organizing ideas in locally owned files.

## Project status

This repository is the initial project outline. No application or whiteboard features have been implemented yet, and platform packaging has not been built.

## Planned direction

- Natural pen input for handwriting and sketching.
- An infinite canvas for exploring and arranging ideas.
- Offline use with locally owned files, without requiring a cloud account.
- Support for Windows, macOS, and Linux, including a Mac version.

These are planned capabilities, not features available today.

## Original work

Chalksmith will be developed as an original implementation. This repository contains no Microsoft binaries, proprietary code or assets, personal whiteboards, or secrets.
